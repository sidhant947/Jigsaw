# Jigsaw Solitaire 🧩

A beautifully tactile, relaxing jigsaw puzzle game built with Flutter.

---

Zero analytics, zero tracking, zero remote servers, and zero cloud sync. All gameplay, progress, and custom assets stay exclusively on your local device.
